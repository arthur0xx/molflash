# صور أدوات chrigsm

ضع هنا **صورة واحدة فقط لكل أداة**. لا تنشئ صورة مختلفة لمدة شهر أو 3 أشهر أو سنة أو تجديد؛ تُعرض هذه التفاصيل كباقات داخل صفحة الأداة.

بعد إضافة ملف مثل `unlock-tool.png`، افتح لوحة الإدارة ثم: **الأدوات والباقات → ابحث عن الأداة → مصدر الصورة: صورة أداة محفوظة → اكتب `/assets/tools/unlock-tool.png` → حفظ**.

نزّل قائمة الأدوات غير المكتملة من زر **تصدير الصور الناقصة** في لوحة الإدارة. استخدم فقط صوراً متاحة علناً ومرتبطة بالأداة نفسها، أو اترك الصورة الافتراضية لـchrigsm إلى أن تضيف صورة موثوقة.
