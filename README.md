# أكواد تيك — متجر أدوات التفعيل

متجر إلكتروني بسيط وحديث لبيع أدوات التفعيل (عِراق سيرفر، حلا تيك، تطبيقات، ألعاب، اشتراكات، أكواد تعبئة) موجه للسوق المغربي، بواجهة عربية RTL كاملة.

## التقنيات
- **الواجهة:** React + Vite (SPA)
- **الخادم:** Node.js + Express
- **قاعدة البيانات:** SQLite (better-sqlite3) — ملف واحد، لا حاجة لخادم DB

## التشغيل
```bash
# الخادم (منفذ 3001)
cd backend
npm install
npm start

# الواجهة (منفذ 5173 مع Proxy للـ API)
cd frontend
npm install
npm run dev
```

## الحسابات التجريبية
| الدور | الهاتف | كلمة المرور |
|---|---|---|
| مدير | 0600000000 | admin123 |
| زبون | 0611111111 | customer123 |

أكواد تعبئة تجريبية: `TARBIB-20` (20) · `TARBIB-50` (50) · `MARHABA-100` (100)

لوحة التحكم المخفية على الرابط: `/admin`

## المميزات
- **الرئيسية:** منتجات مميزة وصفوف أفقية حسب التصنيف
- **المتجر:** تصنيفات، بحث، فلترة بالسعر، ترتيب
- **تفاصيل المنتج:** وصف، خصومات، كمية، منتجات مشابهة
- **الحسابات:** تسجيل/دخول برقم الهاتف + JWT
- **السلة والشراء:** سلة محلية، دفع من المحفظة
- **البروفايل:** محفظة، سجل عمليات، طلباتي مع التتبع، إشعارات
- **تعبئة المحفظة:** أكواد فورية، أو طلب تحويل بنكي/عملة رقمية يوافق عليه المدير، أو إضافة يدوية من المدير
- **لوحة الإدارة المخفية:** إحصائيات، إدارة المنتجات والتصنيفات، إدارة الزبناء والرصيد، **تتبع الطلبات** (قيد المعالجة / ناجح / مرفوض مع استرداد تلقائي)، طلبات التعبئة، توليد أكواد التعبئة، الإعدادات
- **واتساب:** زر عائم، رابط wa.me برسالة جاهزة عند كل طلب/تحديث حالة، ودعم بوابات WhatsApp API (إشعارات تلقائية)

## الواتساب
- **بدون إعدادات:** يفتح المتجر رابط `wa.me` برسالة جاهزة (يضغط عليه الزبون/المدير).
- **مع بوت (إشعارات تلقائية):** ضع في لوحة الإدارة (الإعدادات) رابط الـ API + الرمز من أي بوابة مثل GreenAPI أو UltraMsg أو Meta Cloud API، ثم أضف منطق الإرسال في `backend/src/notify.js` (`sendWhatsApp`).

## تحسينات مقترحة للمستقبل
1. بوابات دفع مغربية جاهزة: **PayTabs MA** أو **CMI** (بوابة بنكية تدعم البطاقات والدفع عند الاستلام) أو **Jumia Pay**.
2. أكواد التفعيل تُخزَّن مشفّرة وتُعرض للزبون تلقائياً عند نجاح الطلب (لا يدوياً).
3. نظام مراجعات وتقييمات للمنتجات.
4. صفحة تتبع شفافة للطلب + QR.
5. تطبيق Telegram بوت للإشعارات + دعم فوري.
6. إصدار متعدد اللغات (AR/FR/EN) مع تبديل العملة (MAD/EUR/USD).
7. نظام كوبونات خصم ونقاط ولاء.
8. حماية إضافية: Rate limiting، CSP، صلاحيات فرعية للموظفين.
9. نسخ احتياطي تلقائي لقاعدة البيانات إلى السحابة.
10. ربط نظام إدارة المخزون للتفعيلات (كمية الأكواد لكل منتج).
