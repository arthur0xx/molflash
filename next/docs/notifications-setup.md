# إعداد إشعارات ChriGsm

هذا المستند يصف متغيرات بيئة الخادم المطلوبة لتفعيل إشعارات الطلبات والدعم. لا تضع أي قيمة في ملفات الواجهة أو مستودع Git. إذا كانت متغيرات واتساب غير مكتملة، يبقى المتجر والطلبات والدعم عاملين، لكن لا تُرسل رسائل تلقائية ولا تعرض الواجهة نجاحًا زائفًا.

| القناة | المتغير | الغرض |
|---|---|---|
| واتساب | `WHATSAPP_ENABLED=true` | تشغيل صريح للقناة الرسمية |
| واتساب | `WHATSAPP_ACCESS_TOKEN` | رمز Meta Cloud API، خادمي فقط |
| واتساب | `WHATSAPP_PHONE_NUMBER_ID` | معرّف رقم الأعمال في Meta |
| واتساب | `WHATSAPP_GRAPH_VERSION` | اختياري؛ الافتراضي `v22.0` |
| واتساب | `WHATSAPP_TEMPLATE_LANGUAGE` | لغة القوالب؛ الافتراضي `ar` |
| واتساب | `WHATSAPP_ADMIN_PHONE` | رقم المدير المغربي بصيغة دولية أو محلية سليمة |
| واتساب | `WHATSAPP_PHONE_VERIFICATION_TEMPLATE` | قالب معتمد يقبل رمز التحقق كمعلمة واحدة |
| واتساب | `WHATSAPP_TEMPLATE_ORDER_RECEIVED` | قالب العميل: رقم الطلب، اسم الخدمة، وصف الحالة |
| واتساب | `WHATSAPP_TEMPLATE_ORDER_PROCESSING` | قالب العميل: رقم الطلب، اسم الخدمة، وصف الحالة |
| واتساب | `WHATSAPP_TEMPLATE_ORDER_COMPLETED` | قالب العميل: رقم الطلب، اسم الخدمة، وصف الحالة |
| واتساب | `WHATSAPP_TEMPLATE_ORDER_DELIVERY_ADDED` | قالب العميل: رقم الطلب، اسم الخدمة، وصف الحالة |
| واتساب | `WHATSAPP_TEMPLATE_ADMIN_ORDER_RECEIVED` | قالب المدير عند طلب جديد، بالمعلمات نفسها |
| واتساب | `WHATSAPP_TEMPLATE_ADMIN_ORDER_PROCESSING` | اختياري؛ تحديث مدير المعالجة |
| واتساب | `WHATSAPP_TEMPLATE_ADMIN_ORDER_COMPLETED` | اختياري؛ تحديث مدير الإكمال |
| واتساب | `WHATSAPP_TEMPLATE_ADMIN_ORDER_DELIVERY_ADDED` | اختياري؛ تحديث مدير التسليم |
| واتساب | `WHATSAPP_TEMPLATE_ADMIN_SUPPORT_NEW` | قالب المدير عند تذكرة دعم جديدة، بمعلمة رقم التذكرة |
| البريد | `EMAIL_SMTP_HOST` | مزود SMTP موثوق ونطاق مُتحقق |
| البريد | `EMAIL_SMTP_PORT` | عادةً `587` لموصل STARTTLS |
| البريد | `EMAIL_SMTP_SECURE` | `false` مع 587 و`true` مع 465 |
| البريد | `EMAIL_SMTP_USER` و`EMAIL_SMTP_PASSWORD` | اعتماد خادمي فقط |
| البريد | `EMAIL_FROM_EMAIL` | عنوان على نطاق مُتحقق، مثل `security@updates.example.com` |
| البريد | `EMAIL_FROM_NAME` | اسم المرسل؛ مثال: `ChriGsm` |
| البريد | `EMAIL_REPLY_TO` | عنوان استقبال الردود عند الحاجة |

> يجب إنشاء قوالب واتساب والموافقة عليها في Meta قبل التفعيل. يفترض التطبيق ترتيب المعلمات المذكور في الجدول؛ إذا كان القالب مختلفًا، عدّل ترتيب المعلمات في طبقة الإشعارات الخادمة قبل التشغيل.

## اختبارات القبول

ابدأ برقم Meta الاختباري. أنشئ طلبًا تجريبيًا، انقل حالته إلى المعالجة ثم الإكمال أو التسليم، وافتح تذكرة دعم. يجب أن يظهر سجل واحد لكل حدث في مجموعة `notificationLogs`، وألا يتكرر السجل عند إعادة المحاولة. جرّب رقم هاتف غير مغربي ورمزًا خاطئًا ورمزًا منتهيًا؛ يجب أن يفشل كل منها برسالة آمنة.

بالنسبة للبريد، استخدم نطاق إرسال مُتحققًا مع سجلات SPF وDKIM وDMARC، ثم اختبر رسالة التحقق والاستعادة في بيئة منشورة. يدعم التطبيق نصًا عاديًا وHTML معًا، لكن موثوقية الوصول تعتمد على مصادقة النطاق وسمعة مزود البريد، لا على تصميم القالب وحده.
