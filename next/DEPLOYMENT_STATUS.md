# حالة تشغيل ChriGsm

## البيئة الحالية

يعمل تطبيق **ChriGsm** من مجلد `next/` على فرع `rebuild/next-firebase` باستخدام Next.js وFirebase وCloudinary وVercel. يعتمد الموقع على بيانات التشغيل الفعلية المتاحة في Firebase، ويعرض حالات فارغة آمنة إذا لم تكن هناك خدمات أو بيانات متاحة.

| المكوّن | الحالة |
|---|---|
| المصادقة والحسابات | Firebase Authentication مع تأكيد البريد الإلكتروني وروابط مخصصة |
| بيانات المتجر والحساب | Firestore عبر مسارات خادمية محمية |
| إدارة الوسائط | Cloudinary للصور المصرح بها |
| لوحة الإدارة | CMC مع صلاحيات المدير وتعديل الرصيد اليدوي الموثق |
| النشر | Vercel |
| الموقع العام | <https://temporary-speedy-jade-mdelya8.vercel.app> |

## التحقق المطلوب قبل كل نشر

1. شغّل `npm run lint` لمراجعة جودة الشيفرة.
2. شغّل `npm run build` للتحقق من بناء الإنتاج.
3. راجع معاينة Vercel للصفحات المتأثرة قبل ترقية النشر إلى الإنتاج.
4. تأكد من أن متغير `NEXT_PUBLIC_APP_URL` يشير إلى عنوان HTTPS العام للتطبيق حتى تعمل روابط تأكيد البريد وإعادة تعيين كلمة المرور داخل صفحات ChriGsm المخصصة.

## ضوابط التشغيل

تُنفذ عمليات الطلبات والدعم والرصيد وتعديلات الإدارة عبر Route Handlers خادمية مع التحقق من هوية المستخدم وصلاحياته. يجب ألّا تُحفظ أي مفاتيح إدارية أو أسرار في مكونات المتصفح أو في المتغيرات العامة.
