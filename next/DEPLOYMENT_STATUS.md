# حالة تسليم إعادة بناء ChriGsm

## النسخة المتاحة محليًا

يتضمن فرع `rebuild/next-firebase` تطبيق **Next.js 16** المنفصل داخل `next/`، مع واجهة متجر عربية متجاوبة، وكتالوج وتصنيفات وخدمات GSM تجريبية، ونموذج حقول ديناميكية لكل خدمة، ومنطقة عميل، ولوحة CMC. جميع الأسعار المعروضة بالدرهم المغربي.

تحتفظ البيانات التجريبية بوسم `demo: true` عند إدخالها إلى Firestore، وتتوفر أوامر `seed:demo` و`clear:demo` لإدخالها وحذفها بأمان عند ربط Firebase. وحتى ذلك الحين، يعمل التطبيق ببيانات محلية واضحة لا تمس أي بيانات إنتاج.

| التدفق | نتيجة التحقق المحلي |
|---|---|
| إنشاء طلب خدمة | ينشئ نموذج TSL Tool Activation طلبًا تجريبيًا بعد التحقق من الحقل الديناميكي |
| منطقة العميل | يظهر الطلب التجريبي الجديد محليًا بالحالة والسعر على المتصفح نفسه |
| لوحة CMC | تعرض الطلبات والمنتجات كمجلدات والتصنيفات والعملاء والمحافظ |
| حذف التصنيف | يتطلب كتابة اسم التصنيف قبل تفعيل الحذف المتسلسل |
| صفحة الدخول | تدعم حسابي المدير والعميل التجريبيين وتوجّه كل دور إلى وجهته |
| حماية CMC | تحجب الإدارة عن غير المسجل والعميل، وتسمح للمدير التجريبي فقط |
| البناء | نجح `npm run build` باستخدام Webpack |

## العوائق الخارجية الوحيدة

لم ينجح دفع فرع إعادة البناء إلى `arthur0xx/molflash` لأن كلًا من رمز GitHub المرسل ومصادقة GitHub المربوطة أعادا `403 Permission denied`. نجح بديل نشر مباشر: أداة Vercel أصبحت مفوضة ومربوطة محليًا بمشروع `chrigsm-next`، لذلك يمكن نشر التحديثات اليدوية مباشرةً. يبقى اعتماد GitHub ذي صلاحية كتابة مطلوبًا فقط للنشر التلقائي من الفرع: إذا كان رمزًا دقيق الصلاحية، اختر المستودع `arthur0xx/molflash` ومنحه **Contents: Read and write**؛ أو استخدم رمزًا كلاسيكيًا بنطاق **repo**. لا تضع الرمز في ملفات المشروع أو في مستودع Git.

تؤجل قاعدة البيانات والمصادقة الحية فقط لأن Firebase Console ما زال يفرض حد إنشاء مشاريع Google Cloud بعد حذف المشروع القديم. البنية، القواعد، وإعدادات المحاكيات وملفات البيئة جاهزة؛ عند زوال الحد، يُنشأ مشروع Firebase مجاني ثم تضاف متغيرات البيئة إلى Vercel.

## ما تبقى لتحويله إلى نظام بيانات حقيقي

الموقع **منشور ومملوك** الآن، لكن النشر التلقائي من GitHub ما زال محجوبًا لأن فرع `rebuild/next-firebase` غير موجود عن بُعد بسبب خطأ الصلاحية السابق. عند توافر اعتماد GitHub قابل للكتابة، يُدفع الفرع ثم يُربط مستودع `arthur0xx/molflash` بمشروع Vercel `chrigsm-next` مع المجلد الجذر `next/`.

بعد إنشاء Firebase مجاني، تضاف متغيرات البيئة من `.env.example` إلى Vercel، ثم تُشغّل `npm run seed:demo` لإظهار البيانات التجريبية في Firestore. عندئذ تصبح المصادقة، العملاء، الطلبات، الأرصدة، التسليم، ورسائل الدعم بياناتًا مشتركة وخاضعة للصلاحيات بدل تخزين المتصفح المحلي.
