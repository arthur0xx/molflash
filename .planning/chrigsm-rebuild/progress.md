## 2026-08-13 — إنشاء Firebase

تم فتح Firebase Console بحساب Google المسجل وبدء إنشاء مشروع باسم `ChriGsm Demo` بلا فوترة. أظهر Firebase أن الحساب بلغ حد عدد مشاريع Google Cloud ولا يمكن إنشاء مشروع جديد حاليًا. ظهر مشروع قائم باسم `device-streaming-c14af3c9`، لكنه غير معروف الغرض لذلك لن يُضاف Firebase إليه أو يُعدّل من دون موافقة صريحة. سيستمر بناء التطبيق حول Firebase Emulator وبيانات تجريبية محلية إلى أن يوفّر المالك مشروع Firebase جديدًا أو يوافق على استخدام مشروع قائم.

ظهر تأكيد الحذف الرسمي لمشروع `device-streaming-c14af3c9`. يؤكد Firebase أن الحذف يشمل مشروع Google Cloud والخدمات وواجهات API المرتبطة به، مع إمكانية الاستعادة من قبل مالك المشروع خلال 30 يومًا. أذن المالك صراحة بحذف هذا المشروع تحديدًا لتحرير حد المشاريع.

أعيد فتح نافذة تأكيد الحذف بعد إغلاقها دون تنفيذ العملية في المحاولة الأولى. تحقق من صفحة الإعدادات أن المشروع لا يحتوي تطبيقات مسجلة ولا يفعّل فوترة؛ ما زال الحذف بانتظار تفعيل تأكيدات الحوار الأربعة وكتابة معرّف المشروع.

اكتمل حذف مشروع `device-streaming-c14af3c9` بنجاح بعد تأكيدات المستخدم. تعرض Firebase أن المشروع حُذف، وأصبح الحساب بلا مشاريع ظاهرة، مما يحرر مساحة لإنشاء مشروع `ChriGsm Demo` الجديد بلا فوترة.

تم إنشاء تطبيق Next.js جديد داخل `next/` على فرع `rebuild/next-firebase` من دون تعديل الواجهة المنشورة. يحتوي التطبيق على متجر وخدمات وكتالوج وتفاصيل طلب ومنطقة عميل ولوحة CMC، ويقرأ من بوابة بيانات موحدة تعود للبيانات التجريبية عندما لا توجد أسرار Firebase. نجح `npm run build` وتم توليد المسارات `/` و`/catalog` و`/service/[slug]` و`/account` و`/admin`.

أضيفت طبقات Firebase Client وFirebase Admin وقواعد Firestore وStorage وإعداد Firebase Emulator. أضيفت أوامر `npm run seed:demo` و`npm run clear:demo` التي تعتمد وسم `demo:true` حتى تحذف البيانات التجريبية فقط. نجح بناء التطبيق مجددًا بعد هذه الإضافات.

بعد حذف المشروع، يعرض Firebase Console مجددًا حد إنشاء المشاريع عند فتح نموذج مشروع جديد؛ يبدو أن حذف المشروع لا يحرر الحصة فورًا. يستمر التطبيق بالوضع المحلي التجريبي إلى حين زوال الحد أو منح حصة إضافية. في المقابل، شُغلت معاينة Next.js المحلية بنجاح على `http://localhost:3000` وظهرت الصفحة الرئيسية العربية وبطاقات خدمات GSM من البيانات التجريبية.

تم التحقق بصريًا من لوحة CMC في المعاينة الحية: مؤشرات العملاء والأرصدة والطلبات وبطاقات مجلدات التصنيفات تظهر من نفس البيانات التجريبية. كما تم فتح تفاصيل `TSL Tool Activation` وتأكيد ظهور السعر بالدرهم المغربي والحق الديناميكي للبريد ونموذج الطلب التجريبي.

تعذر دفع فرع `rebuild/next-firebase` إلى GitHub لأن رمز الوصول الحالي أعاد HTTP 403 عند محاولة الدفع. كما أعاد موصل Vercel 403 عند طلب قائمة أدوات النشر، رغم نجاحه سابقًا؛ لذا لا يمكن إنشاء رابط Preview خارجي من هذه الجلسة حاليًا. لم تُحذف أي ملفات محلية، وتبقى معاينة Next.js الحية عاملة محليًا.
