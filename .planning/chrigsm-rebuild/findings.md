# المكتشفات والمراجع

## قرارات تقنية مثبتة

- مشروع Vercel `chrigsm` مربوط بمستودع `arthur0xx/molflash` مع `frontend` كمجلد جذر وفرع `main` كإنتاج.
- رابط الإنتاج الحالي على Vercel يعمل، لكنه يستضيف واجهة فقط؛ لا يقدّم قاعدة بيانات أو مصادقة حية.
- الموقع الحالي React/Vite مع Express/SQLite محلي، وتوجد واجهات CMC أولية وتصميم مرجعي موثق.

## مصادر البنية

| المصدر | الخلاصة | الرابط |
|---|---|---|
| Firestore listeners | `onSnapshot` يرسل لقطة أولية ثم تحديثات عند تغيير المستندات أو الاستعلامات | https://firebase.google.com/docs/firestore/query-data/listen |
| Firebase pricing | Firebase يقدم طبقة بدء دون تكلفة وخدمات منفصلة للهوية والبيانات والملفات مع حدود استخدام | https://firebase.google.com/pricing |
| MongoDB Atlas | M0 مجاني دائم بسعة 512MB، لكنه قاعدة بيانات لا تكفي وحدها للمصادقة والملفات والتحديث الفوري | https://www.mongodb.com/pricing |
| NocoDB self-hosting | الاستضافة الذاتية تحتاج 2vCPU/2GB RAM على الأقل؛ لا تناسب هدف الاستضافة المجانية الدائمة كقلب النظام | https://nocodb.com/docs/self-hosting |
| Next.js Route Handlers | تدعم مسارات HTTP وعمليات خادمية قريبة من الواجهة | https://nextjs.org/docs/app/getting-started/route-handlers |
| Vite + Vercel | يتيح Vercel معاينات للفروع وإنتاجًا من فرع الإنتاج | https://vite.dev/guide/static-deploy |
| NestJS | خادم TypeScript منظم وقابل للتوسع، لكن يضيف خادمًا مستقلًا لا نحتاجه في النسخة الأولى | https://docs.nestjs.com/ |

## افتراضات تنفيذية

- لا توجد بيانات إنتاج حية تحتاج ترحيلًا الآن؛ البيانات الحالية تجريبية.
- المستخدم يريد تقليل الأسئلة، لذلك تستخدم قرارات هذا الملف كافتراضات افتراضية حتى يغيّرها صراحة.
- لا تنشأ حسابات دفع أو WhatsApp ولا تُرسل رسائل حقيقية أثناء البناء التجريبي.

## نتائج التحقق المحلي

- ظهرت لوحة CMC على المعاينة الحية مع البيانات التجريبية ومؤشرات المحافظ والطلبات بالدرهم المغربي.
- حُجبت بدايةً حزم JavaScript للتطوير بسبب حماية `allowedDevOrigins` في رابط المعاينة المؤقت؛ أضيف النطاق الممنوح إلى `next.config.ts` ثم أُعيد فتح الصفحة.
- بعد ضبط النطاق، نجح تبويب **التصنيفات** في عرض إضافة التصنيف وقائمة التصنيفات وأزرار الحذف، مما يؤكد عمل تفاعل React في المعاينة الحية.
- عُرضت نافذة **الحذف المتسلسل** عند اختيار حذف تصنيف، وتطلبت كتابة اسم التصنيف قبل تفعيل التأكيد. أُغلقت بالمسار الآمن «إلغاء» من دون حذف بيانات تجريبية.
- تحققت صفحة خدمة TSL Tool Activation من عرض حقل البريد الإلكتروني الديناميكي والسعر بالدرهم المغربي، وأنشأت طلبًا محليًا برقم `ORD-DEMO-027183`.
- ظهر الطلب الجديد في منطقة العميل بالحالة «جديد» والسعر **120 د.م.** مع وسم أنه محفوظ على المتصفح، إلى جانب الطلبات التجريبية الأساسية. يحقق ذلك تدفقًا تجريبيًا مترابطًا من الخدمة إلى الحساب قبل ربط Firestore.
- نجح بناء Webpack كاملاً بعد إضافة المكوّنات العميلية وربط الطلبات التجريبية بمنطقة العميل.
- ضمن تنفيذ خطة الصفحة-بصفحة، تم تحديث الغلاف المشترك ليبرز المسار النشط في التنقل العلوي والسفلي. تحققت المعاينة المرئية على الصفحة الرئيسية ثم الكتالوج؛ انتقل مسار «الخدمات» بوضوح إلى الحالة النشطة، وبقيت بطاقة السلة والحساب وروابط CMC ظاهرة ومنظمة.
- فُحصت الصفحة الرئيسية المعاد تنظيمها بصريًا من بدايتها حتى نهاية قسم المتنوع وبطاقة الدعم. تعرض أربعة تصنيفات سريعة مع أعداد الخدمات، وأربع خدمات GSM، وخدمتين رقميتين متنوعتين، وبطاقة دعم؛ تظهر كل الأسعار بالدرهم المغربي ومن دون قسم Hero كبير.
- استجابة لملاحظة تكرار البحث على الهاتف، أزيل زر البحث المنفصل من الرأس واستبدل رمز «الخدمات» السفلي برمز كتالوج. أصبح الكتالوج يحتوي على مربع بحث واحد فعلي وفلاتر تصنيف فقط. فُحص البحث بكلمة `Honor` فأعاد بطاقة Honor FRP Service وحدها مع السعر الصحيح.
- فُحصت منطقة العميل بعد إضافة إعدادات الحساب. تظهر بيانات الاسم والهاتف والبريد مع حفظ تجريبي محلي، كما يظهر بوضوح أن تغيير كلمة المرور سيستخدم رابط Firebase Authentication عند تشغيل المصادقة الحقيقية، بدلاً من محاكاة عملية كلمة مرور غير آمنة.
- فُتح نموذج الدعم الفني ونجح إدخال موضوع الرسالة وتفاصيلها، ومنها رقم الطلب التجريبي. تم حفظ الرسالة التجريبية فعلًا وعرضها في سجل حساب العميل بالحالة «مفتوح». كما ظهرت الرسالة نفسها في تبويب «الدعم» بلوحة CMC مع زر «تم الرد»، ما يثبت التدفق المحلي بين العميل والإدارة. ستتحول إلى سجل Firestore مرئي لفريق CMC بعد الربط.
- في تبويب الطلبات بـCMC، ظهر حقل إدخال كود التفعيل لكل طلب غير مكتمل. أُدخل كود تجريبي `TSL-DEMO-2026-ACTIVE` للطلب TSL قيد المعالجة، ثم نجح زر الإرسال في تغيير الحالة إلى «مكتمل» وإظهار الكود على البطاقة محليًا.
- فُتح تبويب «العملاء والمحافظ» وظهرت قائمة العملاء الثلاثة بأسمائهم وأرقامهم وأرصدة محافظهم وأزرار الإضافة والخصم التجريبية. أضيف كذلك عدد الطلبات لكل عميل وزر «طلبات» لفتح قائمة طلبات هذا العميل مباشرة. فُحص زر ياسين الفاسي فأظهر طلبيه فقط مع زر للعودة إلى كل العملاء. ستصبح هذه العمليات معاملات خادمية مسجلة عند ربط Firebase.
