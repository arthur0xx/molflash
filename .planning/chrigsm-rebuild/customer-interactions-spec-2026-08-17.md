# نظام تفاعلات العميل — ChriGsm

## الهدف

تأكيد نتيجة كل إجراء للعميل بوضوح، وجعل حالة الطلب والإعدادات مقروءة سريعًا، من دون رسوم ثقيلة أو تغيير في مسارات البيانات أو الصلاحيات.

| المنطقة | التحسين | السلوك |
| --- | --- | --- |
| فتح الحساب | هيكل تحميل مرئي | بطاقات وهمية قصيرة ومساحة ثابتة حتى لا يبدو الحساب متوقفًا. |
| حفظ الإعدادات والصورة والدعم | إشعار عابر موحد | نجاح أو معلومات عملية لمدة قصيرة مع `aria-live`، مع بقاء الخطأ قرب الحقل المتأثر. |
| إعدادات الحساب والدعم | فتح/إغلاق واضح | `aria-expanded` وحالة نشطة وانتقال صغير عند الكشف. |
| الطلبات | حالة فارغة عملية | شرح مباشر ورابط إلى الخدمات عند عدم وجود طلبات. |
| حالة الطلب | تفاعل تفاصيل منضبط | توسع تفاصيل الطلب بسلاسة قصيرة، ومؤشرات التركيز واضحة. |
| جميع الواجهات | احترام تفضيل الحركة | إيقاف الانتقالات والحركات عند `prefers-reduced-motion: reduce`. |

## الحدود

لا تتغير الأسعار أو الأرصدة أو صلاحيات الحساب أو حالات الطلب. لا يضاف تتبع خارجي أو مكتبات حركة. تغطى الحركات بخصائص CSS خفيفة مثل `opacity` و`transform` فقط.
