# خطة الاستئناف — ChriGsm

## الهدف الحالي

إصلاح توافق واجهة المتجر وCMC على الهاتف والكمبيوتر، ثم استئناف تجهيز كتالوج Firebase بخدمات تجارية حقيقية فقط.

| المرحلة | الحالة | معيار الإغلاق |
|---|---|---|
| توثيق عيوب الواجهة | مكتمل | لقطات المستخدم ومصدر العيب موثقان. |
| إصلاح التخطيط التكيفي ومساحات اللمس | مكتمل برمجيًا | بطاقات قابلة للنقر كاملة ونوافذ CMC منظمة عبر نقاط التوقف. |
| إصلاح بطاقات الخدمات ونماذج CMC | مكتمل برمجيًا | بطاقة الخدمة رابط كامل؛ نموذج الإضافة/التعديل bottom sheet على الهاتف. |
| تحقق المعاينة الهاتف/الكمبيوتر | قيد التنفيذ | معاينة Vercel، فحص بصري وتفاعلي عند عرضين، دون أخطاء بناء أو متصفح. |
| نشر الإصلاح وتوثيق نقطة استئناف الكتالوج | لم يبدأ | إنتاج بعد نجاح المعاينة، ثم تذكير المالك ببيانات الخدمات التجارية. |

## نقطة استئناف الكتالوج

اكتملت التصنيفات الفعلية في Firebase: **خدمات Server**، **الأدوات**، **كراء الأدوات**، **متنوع**، و**أدوات التفعيل**. لم تُضف خدمات جديدة لأن السعر وطريقة التسليم وحقول العميل لم تُعتمد بعد؛ لا يجوز إدخال أسعار افتراضية لخدمات قابلة للبيع.
