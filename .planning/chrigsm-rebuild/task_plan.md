# خطة إعادة بناء ChriGsm المستقلة

## الهدف

إعادة بناء ChriGsm كتطبيق Next.js + Firebase + Vercel مترابط للمتجر ولوحة CMC ومنطقة العميل، ببيانات تجريبية نظيفة يمكن حذفها واستبدالها بالبيانات الحقيقية دون تعديل جوهري في الكود.

## معايير القبول

- [x] تطبيق Next.js منظم ومنشور على Vercel في مشروع مملوك؛ يبقى الربط التلقائي بالفرع معلقًا لصلاحية GitHub.
- [ ] Firebase Authentication وFirestore وStorage مهيأة من دون أي أسرار في Git.
- [ ] متجر مرتبط ببيانات Firestore ويدعم التصنيفات والمنتجات والحقول الديناميكية.
- [ ] لوحة CMC تحميها صلاحيات المدير وتدير التصنيفات والمنتجات والطلبات والعملاء والأرصدة.
- [ ] منطقة العميل تعرض طلباته وحالتها ورصيده ورسائله.
- [ ] عمليات المحفظة والتسليم تمر عبر API خادمي وسجل تدقيق.
- [ ] بيانات تجريبية في ملف/سكربت واحد يدعم `seed` و`reset` و`clear-demo`.
- [ ] دليل استبدال البيانات التجريبية ببيانات حقيقية.

## القرارات المعتمدة

| القرار | الاختيار | السبب |
|---|---|---|
| إطار التطبيق | Next.js | React موحد مع SSR/SEO ومسارات API موثوقة |
| البيانات والهوية والملفات | Firebase | بيانات فورية ومصادقة وتخزين ضمن منظومة واحدة |
| النشر والمعاينات | Vercel | مربوط أصلًا بـGitHub؛ إنتاج من `main` ومعاينات للفروع |
| NocoDB | اختياري لاحقًا | أداة تشغيل داخلية فقط، وليس مصدر حقيقة النظام |
| NestJS | مؤجل | لا نحتاج خادمًا مستقلًا في النسخة الأولى |

## الاعتماديات الخارجية

| الاعتمادية | الحالة | ما يلزم |
|---|---|---|
| GitHub + Vercel | Vercel متوفر ومشروع `chrigsm-next` مملوك | دفع فرع GitHub ما زال يحتاج صلاحية كتابة فعلية؛ الموقع الحالي يعمل على `temporary-speedy-jade-mdelya8.vercel.app` |
| Firebase | محجوب | إنشاء/ربط مشروع Firebase مجاني بعد زوال حد المشاريع ومنح صلاحية مبدئية للمالك |
| WhatsApp Business | مؤجل | رقم العمل وإعداد Meta عند الوصول لمرحلة التكامل الحقيقي |
| الدفع الحقيقي | مؤجل | بوابة دفع وحساب تجاري بعد اكتمال النظام الأساسي |

## مراحل التنفيذ

| المرحلة | الحالة | المخرج |
|---|---|---|
| 1. تفويض التنفيذ والاعتماديات | مكتمل | تفويض كامل وبيانات تجريبية قابلة للمسح |
| 2. مشروع Next.js وبنية قابلة للتبديل | مكتمل | تطبيق Next.js، طبقة بيانات موحّدة، وقواعد Firebase جاهزة |
| 3. Firebase والبيانات والأدوار | محجوب | القواعد والسكربتات جاهزة؛ مشروع Firebase السحابي لم يُنشأ بعد بسبب حد الحساب |
| 4. المتجر وCMC والعميل | مكتمل تجريبيًا | واجهات وتدفقات محلية للكتالوج، الطلب، الحساب، الدعم، وCMC |
| 5. الاختبار والمعاينة والنشر | مكتمل جزئيًا | بناء إنتاج ناجح وموقع Vercel مملوك؛ الربط التلقائي بـGitHub معلق |
| 6. التسليم والتوثيق | قيد التنفيذ | دليل النشر والاستبدال محدث؛ يتبقى Firebase والنشر التلقائي |
