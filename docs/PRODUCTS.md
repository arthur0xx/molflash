# إدارة كتالوج ChriGsm

الموقع الآن يبدأ ببيانات تجريبية فقط، ولا يعرض صورًا للمنتجات. يمكن تعديل أو إضافة الخدمات من لوحة الإدارة عند تشغيل الخلفية، أو مباشرةً من الملف التالي قبل بناء النسخة الثابتة:

```text
backend/src/data/gsm-services.json
```

كل مجموعة داخل الملف تمثل تصنيفًا في التطبيق. التصنيفات الحالية هي **تفعيل الأدوات** و**خدمات السيرفر** و**كراء الأدوات** و**متنوع**. يتضمن كل عنصر الحقول التالية:

| الحقل | الاستخدام |
| --- | --- |
| `SERVICENAME` | اسم الخدمة الظاهر للعميل. |
| `CREDIT` | سعر تجريبي أو فعلي بالدولار. استخدم `0` لإظهار «سعر تجريبي». |
| `TIME` | ملاحظة قصيرة عن المتابعة أو مدة الباقة. |
| `CUSTOM.customname` | البيانات التي يطلبها النموذج من العميل، مثل اسم المستخدم أو البريد الإلكتروني. |

بعد أي تعديل للبيانات، نفّذ داخل مجلد `frontend`:

```bash
npm run build:preview
```

لا يستخدم التصميم صور المنتجات حاليًا؛ يعتمد على بطاقات وأيقونات رقمية متسقة. عند رغبتك في إعادة إضافة صورة مستقبلاً، أضف مسار الصورة إلى بيانات المنتج أو عبر لوحة الإدارة، وتأكد من إعادة النشر بعد التعديل.
