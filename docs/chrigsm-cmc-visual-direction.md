# اتجاه الواجهة المرجعي للوحة ChriGsm CMC

## الهدف

ستعتمد لوحة CMC نمط لوحة إدارة عربية نظيفة ذات **شريط علوي ثابت** و**شريط جانبي أيمن** و**محتوى تشغيلي قائم على البطاقات والفلاتر**. المراجع المرفقة تحدد أسلوب التنظيم وكثافة المعلومات، لكنها لا تمثل بيانات المتجر أو مجاله؛ لذلك ستُستبدل جميع أمثلة الهواتف والطلبات التجريبية بخدمات ChriGsm الرقمية مثل FRP Unlock وTSL Tool وEFT Pro وHonor FRP وIMEI.

## القرارات المعتمدة

| العنصر | النمط المستهدف | تكييف ChriGsm |
|---|---|---|
| الهيكل العام | شريط علوي أبيض، قائمة جانبية يمينية، منطقة محتوى رمادية فاتحة | شعار **ChriGsm CMC**، بحث شامل، اختصارات دعم وإشعارات وحساب الإدارة |
| نظرة عامة | صف بطاقات مؤشرات ثم نشاط وملخصات تشغيلية | العملاء النشطون، الطلبات الجديدة، الطلبات قيد المعالجة، إجمالي أرصدة المحافظ بالدرهم المغربي |
| المنتجات | أدوات جماعية، فلاتر، بطاقات شبكة متجانسة | بطاقات خدمات رقمية، لا صور أو قطع صيانة هواتف، اختيار متعدد وحالة نشر ومحرر منتج |
| الطلبات | فلاتر الحالة والوقت والسعر ثم بطاقات طلبات | العميل، الخدمة الرقمية، المدخلات الديناميكية، الحالة، المبلغ **د.م.**، وإجراء سريع لفتح المعالجة أو WhatsApp |
| العملاء | بطاقات سهلة المسح تتضمن هوية العميل ورصيده | الاسم، الهاتف، دخول سريع إلى WhatsApp، رصيد المحفظة، آخر عملية وإجراء إدارة الرصيد |
| التصنيفات | صفحة مستقلة عن شبكة المنتجات | مجلدات التصنيفات قابلة للعرض من المنتجات، وتُحرر حصريًا في صفحة التصنيفات مع أيقونة ورابط/رفع وحذف متسلسل مؤكد |

> لا تتضمن واجهة المنتجات صور أجهزة أو أسماء منتجات مادية. تستخدم خدمات ChriGsm أيقونات خطية أو رموزًا مجردة، بينما تبقى صورة الخدمة اختيارية من إعدادات المنتج.

## قواعد التجربة

يجب أن يكون كل جدول أو بطاقة قابلاً للقراءة على سطح المكتب أولًا ثم يتحول إلى عمود واحد منظم على الهاتف. تستخدم البطاقات ظلًا هادئًا وحوافًا دائرية متوسطة، وتقتصر حالة الألوان على الأزرق للإجراء الأساسي، والأخضر للنجاح، والعنبر للمعالجة، والأحمر للرفض أو الحذف. ستبقى جميع مبالغ العرض بالدرهم المغربي بصيغة **د.م.**.

تتضمن الشاشات التي تنفذ إجراءً حساسًا، وبالأخص حذف تصنيف، خطوة تأكيد واضحة: تعرض عدد المنتجات المتأثرة وتتطلب كتابة اسم التصنيف كما هو قبل إتاحة الحذف النهائي.
