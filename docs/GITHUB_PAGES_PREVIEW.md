# معاينة تصميم chrigsm على GitHub Pages

تنشر GitHub Actions الواجهة من `frontend/` إلى GitHub Pages عند كل دفع إلى الفرع `main`. تنفّذ العملية أمر `npm run build:pages` الذي يولّد كتالوجاً ثابتاً من ملف `backend/src/data/gsm-services.json` ثم يبني Vite تحت المسار `/molflash/`.

هذه النسخة المنشورة هي مساحة مرئية حقيقية لمراجعة التصميم العربي، الهوية البصرية، بطاقات الأدوات، التصنيفات، الفلاتر، صفحات الأدوات والباقات، وسلة الواجهة. تستخدم روابط hash لكي يظل التنقل بين الصفحات عاملاً على الاستضافة الثابتة.

| العنصر | حالة GitHub Pages |
|---|---|
| الواجهة، الأصول، التصميم، RTL | متاح |
| الكتالوج الثابت: 535 باقة و363 أداة | متاح ويُعاد توليده عند البناء |
| البحث، الفلاتر، الفرز، صفحات الأدوات، السلة المحلية | متاح |
| تسجيل المستخدمين، المحفظة، لوحة الإدارة، الطلبات والتنبيهات | يحتاج خادم Express وقاعدة بيانات دائمة |
| تنفيذ الطلبات لدى مزود GSM | غير مفعّل عمداً |

لا تحتوي بيانات المعاينة على بيانات دخول أو حسابات أو طلبات تجريبية. عند اعتماد التصميم، يستمر النشر على GitHub Pages كمساحة معاينة، بينما يُنشر خادم Express وSQLite على خدمة دائمة ويُربط عنوانه بالواجهة الإنتاجية عبر `VITE_API_BASE_URL`.
