# حسابات ChriGsm التجريبية

تُنشأ الحسابات التالية **فقط** عند تشغيل خادم التطوير مع المتغير `SEED_DEMO_ACCOUNTS=true`. يتجاهل الخادم هذا المتغير عندما تكون `NODE_ENV=production`، لذلك لا ينبغي اعتبار هذه البيانات حسابات إنتاج أو استخدامها في بيئة عامة.

| الدور | رقم الهاتف | كلمة المرور | الحالة التجريبية |
|---|---:|---|---|
| مدير CMC | `0600000000` | `AdminDemo2026!` | يمكنه فتح `/admin` وإدارة الكتالوج والطلبات والعملاء والمحافظ. |
| عميل | `0611111111` | `ClientDemo2026!` | يمتلك رصيدًا ابتدائيًا مقداره **1,500 د.م.** لتجربة المحفظة والطلب. |

## التشغيل المحلي المعزول

شغّل الخادم باستخدام قاعدة بيانات منفصلة للتجربة، كي لا تختلط الحسابات أو الأرصدة التجريبية مع أي بيانات تشغيلية:

```bash
cd backend
DATABASE_PATH=./data/chrigsm-demo.db SEED_DEMO_ACCOUNTS=true npm start
```

ثم شغّل الواجهة في جلسة أخرى ووجّهها إلى الخادم المحلي:

```bash
cd frontend
VITE_API_BASE_URL=http://127.0.0.1:3001 npm run dev
```

> **تنبيه:** موقع GitHub Pages هو واجهة ثابتة فقط. تسجيل الدخول وإدارة CMC يعملان عندما يكون خادم Express/SQLite مشغّلًا ومتصلًا بالواجهة.
