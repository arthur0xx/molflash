# ChriGsm Storefront Override

> هذا الملف يطغى على نظام التصميم العام عند العمل على واجهة المتجر العامة.

## السياق

ChriGsm متجر مغربي لخدمات GSM الرقمية والتفعيلات. الصفحة الأولى ليست صفحة حملات أو Hero تسويقية، بل نقطة دخول سريعة إلى كتالوج الخدمات. المستخدم يصل غالبًا من هاتفه ويريد البحث، اختيار التصنيف، ثم فتح الخدمة وطلبها.

## قرارات التصميم

| البند | القرار |
|---|---|
| اللغة | عربية RTL، مع إبقاء أسماء الأدوات وروابط slug والرموز التقنية عند الحاجة باتجاه LTR فقط داخل العنصر |
| النبرة | هادئة وواضحة، بلا عبارات ندرة أو وعود تسويقية أو شارات ثقة مصطنعة |
| اللون | كحلي موثوق `#0f2b58`، أزرق تفاعلي `#1768cf`، خلفية ضبابية خفيفة `#f5f7fb`، أخضر للحالات التشغيلية فقط، عنبر للإجراء أو التنبيه فقط |
| الخط | خط نظام عربي سريع، مثل `system-ui, Arial, Tahoma`; لا يعتمد على اقتراح Garamond أو Lato لأنها لا تغطي العربية كحل أساسي |
| التخطيط | حاوية بعرض 1240px، شبكة 1/2/3/4 وفق العرض، ومسافات عمودية متوسطة لا تترك فراغًا ميتًا |
| البطاقة | الصورة أو البديل المرئي جزء كبير من البطاقة، ثم التصنيف، الاسم، وصف من سطرين، التسليم، والسعر. البطاقة كلها رابط واحد |
| الحالة الفارغة | لا تخفِ الأقسام بلا تفسير؛ وضّح أن الكتالوج قيد الإعداد، مع رابط كتالوج أو إجراء إداري فقط حيث تكون الصلاحية متاحة |
| الحركة | انتقالات hover وfocus قصيرة، من دون تحريك دخول يعتمد عليه المحتوى، مع احترام `prefers-reduced-motion` |

## التوقيع البصري

بطاقات الخدمات تستخدم **لوحة تقنية هادئة**: صورة مرفوعة تغطي مساحة الوسيط، أو بديل يحمل حرفين من اسم الخدمة فوق خطوط شبكية دقيقة. لا تُستخدم صور أجهزة صيانة أو عتاد، لأن الكتالوج يقتصر على خدمات Server والتفعيل والكراء والخدمات الرقمية.

## معايير القبول

- لا تمرير أفقي عند 320px أو 390px.
- كل مساحة البطاقة قابلة للنقر أو التركيز.
- الصورة لا تسبب CLS أو تغييرًا في ارتفاع البطاقة.
- السعر والتسليم يظهران دون تمرير داخل البطاقة.
- لا تضيف الواجهة أسعارًا أو خدمات غير موجودة في Firebase.
